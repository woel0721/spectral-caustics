# Phase 3.3 局部 Majorant 基准记录

2026-11-17，macOS arm64，Rust 1.99.1，Release 构建。记录本机结果，不作为其他机器的速度承诺或 CI 时间阈值。算法与运行接口见 [网格介质指南](rendering_guide.md#非均匀密度网格)。

## 方法

在修改传输实现前，将同一份 [公开 API 基准入口](../examples/grid_majorant_benchmark.rs) 编译到 Phase 3.2 的 `4cad54a` 源码上，保存基线二进制；随后用该入口测量局部版本。基线与局部版本串行运行，使用同一组输入和 seed，未在生产实现或正确性测试中保留旧采样器。64³ 基线在局部版本之后再次运行以核对结果。

- 每组 100,000 条射线，重复五次，记录中位数和全部时间值（输出数组按耗时排序）。预生成 4,096 条双向、轻微倾斜的穿盒射线（seed=42），循环使用；采样 seed 为 `17+repeat`。采样计时前预热 4,096 条射线。
- 单段采样使用 `[-1,1]³`、`sigma_a_base=0.05`、`sigma_s_base=0.95`、`g=0.7`。均匀密度为 1；团块在半径 0.3 的球内按抛物线变化、峰值接近 30，球外为零；尖峰场其余密度为 0.05，中心单体素为 128。
- 整图沿用网格雾场景的相机/光源/世界盒，系数为 0.03/0.22，体预算 8，RGB 96×64、16 SPP、seed=42、单线程。计时只包含 `Renderer::render`，不包含场景构建、PNG 或配置保存。采样与整图使用不同世界尺度和系数，因此两类时间分别比较。
- 构造时间独立记录，包含密度复制和局部缓存构造，不计入采样/整图耗时。构造时间只有一次测量，不能当作稳定中位数。
- 候选数由计数 RNG 得到：当前采样器每个候选使用一个 u64 指数随机数和一个 u64 接受随机数；每条路径的奇数尾项是未落在区间内的指数样本。仅穿过零上界块时为零次调用。该统计不进入公共 `MediumSample` 或 Camera Integrator。

## 64³：全局与局部对照

时间单位为毫秒；采样时间对应 100,000 条射线。倍数为“基线耗时 / 局部耗时”。

| 密度场 | 候选/射线：全局 → 局部 | 单段采样：全局 → 局部 | 采样倍数 | 整图：全局 → 局部 | 整图倍数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 均匀 | 0.859 → 0.859 | 7.370 → 8.157 | 0.90× | 481.312 → 499.710 | 0.96× |
| 稀疏团块 | 56.228 → 1.088 | 256.378 → 15.853 | 16.17× | 389.404 → 263.224 | 1.48× |
| 单体素尖峰 | 240.924 → 0.795 | 1,063.709 → 17.857 | 59.57× | 831.007 → 235.900 | 3.52× |

均匀场景的整图耗时增加约 3.8%，采样微基准增加约 10.7%。局部版本没有更多空碰撞，但仍有采样状态、段遍历和检查开销；所有块上界相同时已合并为一个段。细体素遍历采用同一私有 DDA 的编译期专门化，避免在阴影热路径执行粗块的索引运算。

整图收益小于单段采样收益，因为精确阴影透射率、表面求交、体照明和图像累积仍有开销。表中没有将微基准倍数当作渲染器整体倍数。

## 128³：单段采样

此组未测整图。单体素尖峰的物理尺寸随分辨率改变，因此只在相同分辨率内比较基线和局部版本。

| 密度场 | 候选/射线：全局 → 局部 | 单段采样 ms：全局 → 局部 | 采样倍数 |
| --- | ---: | ---: | ---: |
| 均匀 | 0.859 → 0.859 | 7.558 → 9.731 | 0.78× |
| 稀疏团块 | 56.575 → 0.411 | 306.158 → 18.879 | 16.22× |
| 单体素尖峰 | 240.886 → 0.173 | 1,118.041 → 24.323 | 45.97× |

均匀 128³ 微基准耗时增加约 28.8%；该结果也说明局部结构并非对所有密度场都有速度收益。原始数组记录了短微基准的时间波动。

## 分块选择与内存

通过介质内部的 ignored Release 基准比较 2³、4³、8³，不增加 JSON 调参。此基准使用同样的射线/系数，直接替换私有缓存；测试二进制与公开示例的绝对时间不直接混用。

| 块边长（细体素数） | 64³ 局部缓存字节 | 团块采样 ms | 尖峰采样 ms |
| --- | ---: | ---: | ---: |
| 2 | 262,144 | 42.143 | 43.687 |
| 4 | 32,768 | 24.604 | 25.767 |
| 8 | 4,096 | 19.203 | 18.138 |

本轮选择 8：更少的 DDA 跨块开销抵消了更松上界带来的额外候选。均匀场三种设置均合并为单段、缓存 8 字节；其时间差只代表本轮测量波动。

缓存元素为 f64，未合并时占 `8*ceil(nx/B)*ceil(ny/B)*ceil(nz/B)` 字节，另有少量元数据；B=8 时，128³ 为 32,768 字节。该数字不包含原密度数组、JSON 描述或临时构建内存。构建多一次 O(体素数) 的归约：本轮 64³ 局部构造约 1.5–1.9 ms，基线约 0.4–0.7 ms；128³ 局部约 12–23 ms，基线约 3–6 ms。

## 重跑与正确性

命令见 [网格介质指南的基准入口](rendering_guide.md#非均匀密度网格)。将 `GRID_BENCHMARK_CONFIG` 分别指向三种密度场保存的 `config.json`，可重跑私有分块基准。普通 CI 会跳过该时间基准；它已在本轮对三类密度场单独执行。

原始结果和可重跑配置保存在 `output/phase_3_3/`：`baseline_repeat`/`final64`、`baseline128`/`final128`，分块结果在 `tuning_final_*.log`。这些是本地实验输出，不随仓库提交。

正确性由解析碰撞 CDF、跨块光学深度逆变换、独立块 slab 求交、上界覆盖、隐式吸收及多次散射能量验证。Packet CRN 和 1/2/4 线程回归使用真正跨越多个局部块的网格。新旧随机数消耗不同，比较统计分布和能量；同版本固定设置的线程确定性仍要求逐位一致。
